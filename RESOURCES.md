## Remote assets

None by default. The theme makes no remote request and loads no font, script or image from another server. One exception, chosen by the site owner: with Theme Options > Reading and sharing > Google preferred source set to "Google's flow in the page", the pages that show that button load Google's preferred sources library from https://news.google.com/swg/js/v1/publisher.js. The default mode, a plain link to Google's tool, loads nothing.
